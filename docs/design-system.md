# NextStop UI 디자인 시스템

NextStop의 기본 화면은 상아색 바탕에 푸른색으로 현재 이동과 주요 행동을 강조합니다. 사용자에게 가장 먼저 전달할 정보는 노선과 방향, 현재 위치 또는 이동 구간, 다음 정차 지점입니다.

이 문서의 HEX와 컴포넌트 규칙은 초기 UI 결정입니다. 앱 화면에는 기본 팔레트를 적용하고 시스템 알림에는 OS가 허용하는 범위에서 적용합니다. 구현용 값은 [디자인 토큰](design-tokens.json)을 사용합니다.

## 기본 색상

| 토큰 | HEX | 용도 |
| --- | --- | --- |
| primary | `#2457C5` | 메인 블루, 추적 시작 버튼, 선택 항목, 현재 위치 |
| primaryStrong | `#173F8A` | 강조 제목, 눌린 버튼, 다음 정차 지점 |
| primarySoft | `#E7EEFC` | 선택 카드와 블루 배지의 연한 배경 |
| background | `#FFF8E7` | 화면 전체 상아색 배경 |
| surface | `#FFFCF5` | 카드, 입력창, 시트의 밝은 상아색 |
| surfaceMuted | `#F1E9D8` | 보조 영역과 비활성 버튼 배경 |
| textPrimary | `#172B4D` | 본문과 제목의 짙은 남색 |
| textSecondary | `#53627A` | 보조 설명, 지나온 역명, 데이터 시각 |
| onPrimary | `#FFFFFF` | 메인 블루 버튼 위 글자와 아이콘 |
| borderDecorative | `#D8D4C7` | 카드의 장식 구분선 |
| borderControl | `#7B8796` | 입력창·체크박스 등 경계 식별이 필요한 요소 |
| success | `#25634A` | 확인 완료와 성공 상태 |
| warning | `#946200` | 갱신 지연과 확인 필요 상태 |
| danger | `#B42318` | 오류와 종료 동작 |

상아색 두 배경의 차이가 작으므로 카드 경계를 색상 차이만으로 전달하지 않습니다. 카드 제목과 여백을 사용하고, 입력 요소는 borderControl 또는 충분한 대비의 밑줄로 식별합니다. borderDecorative는 필수 정보나 입력 경계에 사용하지 않습니다.

브랜드 블루는 현재 위치와 행동을 나타냅니다. 교통 노선의 공식 색상을 사용할 경우 공급자 데이터의 별도 메타데이터로 관리하고 노선명·번호를 함께 표시합니다. 모든 지하철 노선 색상을 브랜드 블루로 재정의하지 않습니다. 공식 노선 색상의 글자 대비가 부족하면 해당 색상을 작은 배지나 아이콘에만 적용합니다.

## 색상 대비

아래 값은 지정 HEX의 sRGB 상대 휘도로 계산했습니다. 실제 화면과 알림의 투명도·OS 보정·다크 모드 결과를 확인한 수치는 아닙니다.

| 전경과 배경 | 대비 비율 | 적용 |
| --- | --- | --- |
| onPrimary / primary | 약 6.47:1 | 메인 버튼 글자 |
| primary / background | 약 6.11:1 | 링크와 강조 글자 |
| textPrimary / background | 약 13.32:1 | 본문과 제목 |
| textSecondary / background | 약 5.84:1 | 보조 설명 |
| textSecondary / surface | 약 6.04:1 | 카드 보조 설명 |
| primaryStrong / primarySoft | 약 8.53:1 | 선택 배지 |
| borderControl / background | 약 3.45:1 | 입력 경계 |
| borderControl / surface | 약 3.57:1 | 입력 경계 |
| warning / background | 약 4.95:1 | 지연 문구 |
| danger / background | 약 6.21:1 | 오류 문구 |
| success / background | 약 6.70:1 | 확인 완료 문구 |

앱의 디자인 검증 기준은 일반 텍스트 4.5:1 이상, 필수 UI 경계와 그래픽 3:1 이상입니다. WCAG의 해당 기준을 앱의 접근성 점검 목표로 사용하며, 이것만으로 앱 전체 접근성 준수를 선언하지 않습니다. [텍스트 대비 기준](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html), [비텍스트 대비 기준](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)

## 글자와 간격

Android는 시스템 한글 글꼴과 sp, iOS는 시스템 한글 글꼴과 Dynamic Type을 사용합니다. 토큰의 글자 크기는 기준값이며 사용자의 큰 글자 설정에 따라 확장합니다. 간격과 모서리 토큰은 Android dp와 iOS pt에 대응하는 논리 단위입니다.

| 요소 | 기준 크기 | 굵기 |
| --- | --- | --- |
| 화면 제목 | 24 | Bold |
| 현재 위치 | 22 | Bold |
| 섹션 제목과 카드 제목 | 18 | Semibold |
| 본문과 버튼 | 16 | Regular 또는 Semibold |
| 보조 설명 | 14 | Regular |
| 앱 노선도의 주변 역명 | 12 | Medium |

기본 간격은 4, 8, 12, 16, 24, 32입니다. 화면 좌우 여백은 20, 카드 내부 여백은 16, 카드 사이 간격은 12를 사용합니다. 카드 모서리는 16, 입력창과 버튼은 12, 상태 배지는 알약 형태를 사용합니다.

주요 버튼 높이는 기본 52이며, 큰 글자에서는 높이를 늘립니다. 초기 터치 영역 기준은 Android 최소 48dp, iOS 최소 44pt로 정합니다. 주변 역명 때문에 주요 버튼이나 현재 위치 글자를 축소하지 않습니다.

## 컴포넌트

| 컴포넌트 | 기본 상태 | 선택 또는 강조 상태 |
| --- | --- | --- |
| 주요 버튼 | primary 배경, onPrimary 글자 | 눌림은 primaryStrong |
| 보조 버튼 | surface 배경, primary 글자, primary 테두리 | 선택은 primarySoft |
| 노선과 차량 카드 | surface 배경, textPrimary 제목 | primarySoft 배경, primary 경계, 체크 아이콘 |
| 검색 입력 | surface 배경, borderControl 경계 | primary 경계, 명확한 포커스 표시 |
| 실시간 지원 배지 | primarySoft 배경, primaryStrong 글자 | ‘실시간’ 텍스트와 아이콘 |
| 시간표 배지 | surfaceMuted 배경, textPrimary 글자 | ‘시간표 예상’ 텍스트 |
| 갱신 지연 | warning 문구와 시계 아이콘 | 데이터 시각 함께 표시 |
| 오류 | danger 문구와 오류 아이콘 | 재시도 또는 차량 재선택 |
| 종료 버튼 | danger 텍스트와 명확한 버튼 영역 | 사용 중인 추적을 종료 |

비활성 버튼은 surfaceMuted 배경을 사용하고 ‘차량을 선택해 주세요’처럼 필요한 행동을 안내합니다. 선택 여부·오류·지연은 색상과 함께 체크, 아이콘 또는 문구로 구분합니다.

## 가로 노선도

### 정류장 또는 역 도착

```text
2호선 · 역삼·잠실 방면
현재 강남역 도착 확인                  다음 역삼역

방배 ─ 서초 ─ 교대 ─ ●강남 ─ 역삼 ─ 선릉 ─ 삼성
       지나온 역         현재         앞으로 갈 역

삼성역까지 3개 역                 데이터 기준 14:32:10
```

중앙은 현재 정차 지점입니다. 이전 3개는 왼쪽, 앞으로 실제 정차할 3개는 오른쪽에 둡니다. 선과 역명은 각각 다음 규칙을 사용합니다.

| 요소 | 색과 형태 |
| --- | --- |
| 지나온 지점 | textSecondary 글자와 실선, 작은 완료 체크 |
| 현재 지점 | primary 채운 원, 굵은 현재 역명, ‘현재’ 표시 |
| 다음 지점 | primaryStrong 굵은 역명, 테두리 원 |
| 이후 지점 | textSecondary 역명, borderControl 테두리 원 |
| 이동 방향 | 상단 방향 문구와 다음 지점 방향 화살표 |

### 정류장 또는 역 사이 이동

```text
2호선 · 역삼·잠실 방면
현재 교대역 → 강남역 이동 중             다음 강남역

방배 ─ 서초 ─ 교대 ─ [이동 중] ─ 강남 ─ 역삼 ─ 선릉
       지나온 역          현재 구간         앞으로 갈 역
```

이동 중에는 중앙이 역이 아닌 구간입니다. 지나온 3개와 다음 3개 정차 지점을 배치하고, 중앙 구간 표시를 추가합니다. 위 예시의 왼쪽 교대와 오른쪽 강남이 중앙 구간의 출발·도착 지점입니다. 동일한 역명을 노선도의 별도 노드로 중복 표시하지 않습니다.

위치 좌표나 구간 진행률이 없으면 중앙 표시를 움직이는 실제 차량 위치처럼 표현하지 않습니다. ‘이동 중’은 구간 상태를 뜻하며 구간 내 정확한 거리·속도를 뜻하지 않습니다.

### 크기와 예외

앱 내부에서는 가로 스크롤로 주변 경로를 확인할 수 있지만 현재 위치 중심으로 복귀하는 기능을 제공합니다. 알림과 Live Activity의 노선도는 고정 표시이며 스크롤을 전제로 하지 않습니다.

7개 지점이 들어가는 화면에서는 주변 이름을 최대 두 줄로 배치합니다. 긴 이름은 주변 노드에서만 말줄임하고 현재·다음 정차 지점은 상단에 전체 이름을 표시합니다. 공간이 부족하면 3개 지점 요약 또는 텍스트 요약으로 전환합니다. 이전 3개와 다음 3개는 충분한 공간이 있는 표시에서의 목표이며, OS 알림의 모든 크기에서 강제하지 않습니다.

종점에서는 존재하는 지점만 표시하고 빈 자리에 가짜 지점을 넣지 않습니다. 순환 노선은 실제 다음 운행 구간에 따라 연결합니다. 급행은 실제 정차 지점 중심으로 배치하며 통과역을 표시하는 상세 보기에서는 정차역과 형태·문구를 구분합니다.

스크린리더에는 노선도 선과 점을 개별 장식으로 읽히지 않고 ‘2호선, 역삼·잠실 방면, 강남역 도착 확인, 다음 역삼역, 삼성역까지 3개 역’처럼 읽기 순서를 제공합니다. 현재 상태 변화마다 지나온 전체 역명을 다시 읽지 않습니다.

## 플랫폼별 표시 구성

| 표시 위치 | 우선 정보 | 노선도 처리 |
| --- | --- | --- |
| Android 접힌 지속 알림 | 노선·방향, 현재 상태, 다음 지점 | 요약 텍스트 |
| Android 펼친 커스텀 알림 | 현재·다음, 이전·다음 3개, 기준 시각 | 공간이 허용하면 7개 지점 |
| Android 헤드업 도착 알림 | 도착 지점, 다음 지점, 하차 안내 | 텍스트 우선 |
| Android Live Updates | 노선, 진행 상태, 다음 지점 | 시스템 ProgressStyle 사용 |
| iOS 잠금화면 Live Activity | 노선·방향, 현재·다음, 기준 시각 | 7개 지점과 축약 레이아웃 |
| Dynamic Island 작은 표시 | 노선 아이콘과 남은 지점 수 또는 다음 지점 | 노선도 생략 |
| Dynamic Island 확장 표시 | 현재 구간, 다음 지점, 하차까지 남은 지점 | 공간에 따른 요약 |
| iOS 일반 배너 | 도착 지점과 다음 지점 | 시스템 텍스트 배너 |

Android 커스텀 알림은 블루 강조와 OS에 맞는 텍스트 색상을 사용하고, 전체 배경색을 강제로 지정하지 않습니다. Live Updates는 시스템 스타일을 사용합니다. iOS Live Activity도 밝기·잠금화면·항상 켜짐 상태의 시스템 처리를 고려해 색상을 적용합니다. 브랜드 HEX는 앱 화면의 기준이며 시스템 표시에서는 읽기 쉬운 상태를 우선합니다.

## 화면 구성

Android 앱은 스크롤을 줄이기 위해 아래 구성의 간결한 변형을 사용합니다. 소개 문구와 하단 탭을 생략하고, 검색·차량 선택·하차 설정을 별도 화면으로 표시합니다. 검색 조건·방향 필터와 하단 주요 버튼은 목록 바깥에 고정합니다. 이동 중에는 현재·다음 위치, 시각, 요약 노선, 하차 정보를 우선 표시하며 알림은 한 줄 선택창으로 변경합니다. 전체 경로·차량 변경·안내 기록은 이동 상세, API 키·조회 간격은 상단 설정에서 엽니다. 폭 400dp 미만 또는 글자 배율 1.3 이상에서는 주변 노선을 3개 지점으로 요약합니다. 큰 글자·긴 이름에서는 본문 스크롤을 허용하고 버튼의 48dp 터치 영역을 유지합니다. 상세 동작은 [Android 안내](android.md#화면과-스크롤)를 따릅니다. 아래 홈 소개와 시스템 알림 미리보기 구성은 React 웹 미리보기에 해당합니다.

홈은 상아색 배경 위에 교통수단 선택과 검색창을 배치합니다. 현재 추적 중인 이동이 있으면 블루 강조 카드로 가장 먼저 보여 줍니다. 검색 결과에는 지역·노선명과 지원 상태를 함께 표시합니다.

탑승 선택 화면은 노선·방향·탑승 지점을 상단에 고정하고 차량 후보를 카드 목록으로 표시합니다. 후보의 현재 위치와 데이터 시각을 같은 카드에 두어 오래된 후보를 새 정보처럼 보이지 않게 합니다. 차량 선택 후 하단 주요 버튼으로 추적을 시작합니다.

이동 중 화면은 현재 위치를 가장 큰 글자로 표시하고 바로 아래에 가로 노선도를 배치합니다. 다음 정차 지점과 하차까지 남은 지점 수를 별도 영역으로 표시합니다. 데이터 시각과 지연 상태는 노선도 가까이에 둡니다. 차량 변경과 추적 종료는 화면 하단에 제공합니다.

알림 설정은 모드 선택과 현재 선택한 알림의 미리보기를 함께 표시합니다. 플랫폼마다 다른 실제 알림 형태를 보여 주며 커스텀 노선도가 모든 배너에 표시되는 것처럼 안내하지 않습니다.

## UI 검증 기준

- 메인 블루와 상아색 HEX를 토큰으로 사용하고 화면마다 다른 유사 색상을 추가하지 않는다.
- 밝은 모드와 다크 모드에서 일반 글자와 필수 그래픽 대비를 확인한다.
- 긴 정류장 이름과 큰 글자에서 현재·다음 지점과 갱신 지연을 우선 표시한다.
- 색상 없이도 현재·이전·다음·선택·지연 상태를 구분할 수 있다.
- 화면 폭과 OS 알림 크기가 작아지면 자동으로 요약하며 읽기 어려운 작은 글자를 강제하지 않는다.
- 노선도의 역 순서는 이동 방향과 실제 정차 경로에 일치한다.
- VoiceOver와 TalkBack으로 차량 선택, 추적 시작·종료와 현재 위치를 확인할 수 있다.
- 알림의 밝은 모드·다크 모드·잠금화면에서 텍스트가 배경에 묻히지 않는다.
